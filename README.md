
> 텍스트 기반 강화/상점 시뮬레이션 게임
> Rust · Layered Architecture 기반 개발

---

## 📌 프로젝트 소개

**대장장이 게임(Blacksmith Game)** 은 콘솔 기반으로 진행되는
강화·상점·아이템 시스템을 갖춘 시뮬레이션 게임입니다.

플레이어는

* 검을 구매하고
* 강화 시스템을 통해 검을 성장시키며
* 필요하면 검을 판매하여 골드를 얻습니다.

강화 확률, 강화 축복 부적, 파괴 방지권 등 MMORPG에서 사용하는 메커니즘을
직관적이며 확장 가능한 Rust 구조로 설계했습니다.

> 이 프로젝트는 **우아한테크코스(woowacourse) 미션 방식**을 참고하여,
> 테스트 가능하고, 역할이 명확히 분리된 구조를 지향합니다.

---

## 🎯 개발 목표

* Rust 언어로 **Layered Architecture**(Controller / Service / Model / View) 구현
* 메시지, 입력, 출력, 비즈니스 로직을 명확히 분리
* TDD 기반 단위 테스트 + 통합 테스트 구성
* 확장성 있는 도메인 구조 설계
* 콘솔 입출력 기반 UI 구성

## 🧱 레이어 아키텍처 (Layered Architecture)

| 레이어            | 역할                             |
| -------------- | ------------------------------ |
| **Controller** | 메뉴 흐름 제어, 사용자 입력에 따라 로직 연결     |
| **Service**    | 핵심 비즈니스 로직 (강화, 가격 계산 등)       |
| **Model**      | 도메인 객체 (검, 플레이어)               |
| **View**       | InputView / OutputView로 입출력 분리 |
| **Message**    | 출력/입력 메시지 상수 관리                |

## ⚔ 주요 기능

### 1️⃣ 강화 시스템

* 0강 ~ 7강까지 존재
* 강화 확률: 100% → 10%로 점점 감소
* 강화 시 아이템 사용 가능

  * **파괴 방지권**: 실패해도 아이템 파괴되지 않음
  * **강화 축복 부적**: 강화 확률 +5% 상승

단계별 강화 성공 여부는 service 레이어에서 결정합니다.

---

### 2️⃣ 상점 시스템

* **구매 가능**

  * 검 (기본 0강)
  * 파괴 방지권
  * 강화 축복 부적
* **판매 가능**

  * 인벤토리의 검 중 하나 선택
  * 강화 단계에 따라 가격 증가

    * 0강 → 원가보다 10% 낮음
    * 1강 → 원가보다 10% 높음
    * ...
    * 7강 → 원가보다 70% 높음

---

### 3️⃣ 메뉴 시스템

프로그램 시작 시 다음 메뉴 제공:

```
1. 강화 하러 가기
2. 상점
3. 나가기
(0을 누르면 이전 화면으로 돌아갑니다)
```
